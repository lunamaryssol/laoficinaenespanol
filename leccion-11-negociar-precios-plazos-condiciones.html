Negocia

Aprende a usar el condicional, estructuras de cortesía, condiciones y formas de acuerdo o desacuerdo para negociar precios, fechas y alternativas en español.

Condicional Cortesía Condiciones Acuerdo y desacuerdo
Al terminar: podrás proponer y responder a una contraoferta, aceptar o rechazar con cortesía, expresar una condición y justificar brevemente tu decisión.
1 · Encuentra la lengua

Una propuesta cambia

Una empresa está renovando un servicio con un proveedor. El precio, la fecha de entrega y la forma de pago todavía pueden cambiar.

Tu objetivo lingüístico: observa cómo las personas hacen propuestas menos directas, expresan condiciones, justifican una decisión y responden sin usar frases demasiado rígidas.

Activa lo que ya sabes

Las dos frases pueden entenderse. ¿Cuál presenta la petición de forma más cortés y negociable?

2 · Observa

Mira qué cambia

Lee este intercambio. Las palabras resaltadas son herramientas que vas a reutilizar.

CLIENTENos gustaría mantener el precio actual. ¿Sería posible entregar el martes?
PROVEEDORPodríamos entregar el miércoles si confirman hoy.
CLIENTEEl miércoles nos funciona, pero necesitaríamos mantener el mismo precio.
PROVEEDORDe acuerdo. Podemos aceptar esa condición si el pago se realiza esta semana.

¿Qué notas?

El condicional aparece en gustaría, sería, podríamos, necesitaríamos. Ayuda a presentar propuestas o peticiones de forma menos directa.

¿Dónde está la condición?

En estructuras con si + presente: “si confirman hoy”, “si el pago se realiza esta semana”.

3 · Aprende la herramienta

Cuatro recursos para negociar en español

No necesitas dominar todo el condicional. En esta lección vas a trabajar formas frecuentes que sirven para proponer, pedir, condicionar y responder.

1. Proponer con condicional
Podríamos + infinitivo
Podríamos cambiar la fecha.
Podríamos mantener el precio.

Sirve para presentar una opción sin imponerla.

2. Pedir con cortesía
¿Sería posible + infinitivo...?
¿Sería posible entregar el martes?
Nos gustaría + infinitivo
Nos gustaría revisar las condiciones.
3. Expresar una condición
si + presente
Podemos confirmar hoy si mantienen el precio.
Podríamos aceptar el plazo si incluyen el soporte.
Evita: “si podrían entregar...”. En una condición real de este tipo, usa si + presente: “si pueden entregar...”.
4. Acordar o discrepar
Acuerdo: “De acuerdo.” / “Esa opción nos funciona.”
Acuerdo con condición: “Podemos aceptar si mantienen el precio.”
Desacuerdo: “Entiendo la propuesta, pero no podríamos aceptar ese plazo porque necesitamos entregar el proyecto el viernes.”

“No podemos” también es correcto; “no podríamos” suele sonar menos tajante en una negociación. Para justificar una decisión, puedes reciclar una estructura conocida: porque + razón.

Cómo reconocer el condicional que necesitas aquí

En los verbos regulares, el condicional conserva el infinitivo y añade terminaciones que empiezan por -ía: necesitar → necesitaría / necesitaríamos. Algunos verbos frecuentes cambian la raíz: poder → podría / podríamos. También vas a encontrar ser → sería y gustar → gustaría.

No necesitas memorizar toda la conjugación para esta práctica. Necesitas reconocer y recuperar estas formas frecuentes.

Patrones que conviene recuperar

Podríamos + infinitivo ¿Sería posible + infinitivo...? Nos gustaría + infinitivo si + presente Entiendo..., pero... porque + razón
4 · Comprueba

Elige por forma y significado

Responde las cuatro preguntas. Puedes corregir cada respuesta antes de continuar.

5 · Construye

Arma la respuesta

Pulsa las palabras en orden. No necesitas arrastrar: funciona igual en móvil, teclado y escritorio.

6 · Recupera

Ahora sin modelo completo

Escribe una frase breve. La comprobación busca las estructuras trabajadas; no intenta evaluar todas las respuestas posibles.

Empieza con: Podríamos...
Puedes usar: ¿Sería posible...?
Incluye si + presente: “... si mantienen / incluyen / pueden...”
7 · Reacciona

Una contraoferta, tres decisiones lingüísticas

No estás resolviendo una estrategia comercial. Estás eligiendo español que te permita proponer, condicionar y responder.

Propuesta actual

  • Precio: 1.200 USD
  • Entrega: viernes
  • Pago: esta semana

Proveedor

“Podemos mantener el precio, pero la entrega tendría que ser el viernes.”

Quieres proponer el miércoles.

Proveedor

“Podemos entregar el miércoles si aceptan un costo adicional de 80 USD.”

Quieres aceptar el miércoles solo si mantienen el precio.

Proveedor

“Podemos mantener el precio si el pago se realiza esta semana.”

La condición te funciona.

Has recorrido una negociación breve

Has utilizado tres funciones distintas: proponer → condicionar → acordar.
