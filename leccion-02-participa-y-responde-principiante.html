Spanish at Work · Lección 02

Participa y responde

Presente + y, pero, porque + opinión + preguntas

Aplicación: participar en una conversación sencilla de trabajo.

Al terminar: podrás dar una opinión corta, decir si estás de acuerdo, dar una razón sencilla y pedir que repitan algo.

Escucha y observa

Una conversación corta

Lee primero. Después puedes escuchar. No necesitas entender cada palabra.

Marta Creo que necesitamos enviar el informe hoy. Opinión + presente
Leo Sí, estoy de acuerdo, pero necesitamos revisar el informe. Reacción + pero
Marta El cliente necesita el informe a las tres. Presente
Leo ¿A qué hora necesita el informe? Pregunta
Marta A las tres. Respuesta corta
Leo Perdón. ¿Puedes repetir, por favor? Pedir aclaración
Primero observa la conversación. Después mira qué español usa cada persona.

Palabras importantes

  • informe: documento de trabajo.
  • cliente: persona o empresa que compra algo o usa un servicio.
  • enviar: mandar un documento o mensaje.
  • revisar: mirar algo para comprobarlo.
  • hoy: este día.
  • a las tres: hora: 3:00.

Activa lo que ya sabes

¿Qué puedes decir?

Un compañero dice: «Necesitamos enviar el informe hoy». Quieres decir que piensas lo mismo.

Elige una respuesta.

Aprende la herramienta

Cuatro recursos pequeños

Aprende formas cortas que puedes usar muchas veces.

1. Dar una opinión

Usa creo que antes de tu idea.

Creo que necesitamos más tiempo.
Creo que mañana es mejor.

Estructura: Creo que + idea.

2. Reaccionar

Para decir que piensas lo mismo:

Estoy de acuerdo.

Para decir que piensas diferente:

No estoy de acuerdo.

Recuerda: estar de acuerdo.

3. Conectar ideas

y añade una idea.

Necesitamos el informe y la fecha final.

pero muestra una diferencia.

Estoy de acuerdo, pero necesitamos confirmar la hora.

porque da una razón.

Prefiero mañana porque hoy tengo una reunión.

porque = razón. ¿Por qué? = pregunta.

4. Preguntar y pedir ayuda

¿Qué necesitas?
¿Cuándo es la reunión?
¿Quién tiene el informe?
¿Puedes repetir, por favor?

Usa preguntas cortas. No necesitas una frase larga.

Presente: mira una forma básica

No necesitas aprender todas las formas del verbo ahora. Mira este patrón con necesitar.

yonecesito
túnecesitas
él / ellanecesita
nosotrosnecesitamos
En la conversación viste: «necesitamos enviar el informe» y «el cliente necesita el informe».

Ahora dilo tú

Habla durante 30 segundos

Tu respuesta puede ser muy corta. El objetivo es usar las estructuras sin leer una respuesta completa.

Situación
Tu compañero dice: «Creo que mañana es mejor». Responde y haz una pregunta.
Estoy de acuerdo. No estoy de acuerdo. porque… ¿A qué hora…? ¿Quién…?
Objetivo
1 reacción + 1 idea + 1 pregunta
00:30
Puedes comenzar con Estoy de acuerdo o No estoy de acuerdo. Después añade una idea corta y una pregunta.
Revisa lo que dijiste. Si falta una parte, prueba otra vez.
